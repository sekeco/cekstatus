# ✅ CekStatus — Platform Tracking Pesanan & Servis #1 untuk UMKM Indonesia

**CekStatus** adalah platform white-label yang memungkinkan bisnis apa pun memberikan pengalaman _tracking_ ala J&T / Gojek ke pelanggan mereka sendiri — tanpa perlu ngoding, tanpa aplikasi mahal, tanpa ribet.

Cocok untuk: servis laptop, bengkel motor, laundry, cetak foto, reparasi HP, tailor, dll.

> 🚀 **1 sistem — tak terbatas jenis bisnis.**

### 👥 Data Customer — Profil & Riwayat Pelanggan

Semua pelanggan yang pernah kamu layani tercatat otomatis. Dari situ kamu bisa:

- **Lihat semua customer** — nama, nomor HP, email, alamat
- **Cari**: Ketik nama / no HP / email
- **Tambah customer baru**
- **Edit atau hapus** (customer yang masih punya item aktif gak bisa dihapus)
- **Lihat jumlah total item** yang pernah dikerjain per customer — langsung kelihatan siapa _customer setia_.

> 💡 **Contoh real:** Kamu buka customer "Budi Santoso" — langsung kelihatan dia udah servis 5x kali. Keren buat nawarin promo.

### 🔍 Halaman Tracking Publik — Pelanggan Cek Sendiri

Ini **fitur andalan** CekStatus. Pelanggan bisa cek status barangnya dari HP tanpa perlu login:

```
╔══════════════════════════════╗
║  🔍 Cek Status Pesanan      ║
║                              ║
║  ┌──────────────────────┐   ║
║  │ TRK-202406-001        │   ║
║  └──────────────────────┘   ║
║  [🔍 Cek Status]            ║
╚══════════════════════════════╝
```

Hasilnya:

| Seen                                                                                  |
| ------------------------------------------------------------------------------------- |
| ✅ **Status: 🟢 Selesai** — Perangkat Anda sudah selesai diperbaiki, biaya Rp 180.000 |
| Detail: Laptop ASUS ROG masuk 20 Juni 2024                                            |
| Keluhan: Tidak bisa menyala                                                           |
| Catatan: Bersihkan cooling fan, ganti thermal paste                                   |

**Cara kerja untuk pelanggan:**

1. Kamu kasih kode tracking ke pelanggan (bisa ditulis di nota / dikirim via WA)
2. Pelanggan buka link CekStatus dari HP
3. Masukkan kode → langsung tahu status terbaru

> 🚫 **Gak ada telfon "Mas, jadi kapan?"** lagi. Pelanggan cek sendiri.

## 📱 Cara Pakai — Per Role

### 👤 Admin / Pemilik

| Mau ngapain?                   | Caranya                            |
| ------------------------------ | ---------------------------------- |
| Lihat kondisi bisnis hari ini  | Buka **Dashboard**                 |
| Catat item baru                | **Items** → **Tambah**             |
| Ubah status                    | **Items** → **Detail** → **Edit**  |
| Cari item lama                 | **Items** → ketik di **Cari**      |
| Tambah customer                | **Customer** → **Tambah Customer** |
| Edit profil bisnis             | **Pengaturan** → isi → **Simpan**  |
| Atur status & warna            | **Pengaturan** → **Atur Status**   |
| Cek halaman tracking pelanggan | Klik **Cek Status Publik** di menu |

### 👨‍🔧 Karyawan / Teknisi

1. Buka **Items**
2. Filter status **Antrian** — lihat kerjaan baru
3. Klik **Detail** — baca deskripsi/keluhan
4. Habis ngerjain — **Edit** → ubah status

### 👪 Pelanggan (tanpa login!)

1. Buka link tracking yang dikasih toko
2. Masukkan kode (contoh: `TRK-202406-001`)
3. Langsung lihat status terbaru

## ❓ Tanya Jawab

**Q: Apakah data aman?**
A: Data disimpan di komputermu sendiri. Bukan di cloud orang lain. Kamu pegang kendali penuh.

**Q: Bisa dipakai di HP?**
A: Bisa. Tampilan web-nya responsif — rapi di HP, tablet, dan laptop.

**Q: Pelanggan perlu install aplikasi?**
A: Gak perlu. Cukup buka link dari HP, masukin kode, liat hasil. Selesai.

**Q: Cara dapetin kode tracking?**
A: Otomatis dibuat pas kamu tambah item baru. Format: `TRK-TAHUNBULAN-NOMOR`. Kasih ke pelanggan (WA atau ditulis di nota).

**Q: Bisa dipakai untuk banyak toko/cabang?**
A: Versi sekarang untuk 1 toko. Tapi sistemnya udah siap dikembangin untuk multi-cabang.

**Q: Bisnis saya bukan servis laptop — cocok?**
A: **Iya.** CekStatus dirancang universal. Mau laundry, bengkel, percetakan, tailor — semua cocok. Namanya tinggal disesuaikan.

**Q: Ada biaya bulanan?**
A: **Gratis.** Nanti mungkin ada fitur premium buat power user, tapi fitur dasar tetap gratis.
